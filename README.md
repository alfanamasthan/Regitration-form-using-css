
# Student Registration Form

 A simple Student Registration Form created using HTML and CSS.

 The project demonstrates basic form elements, styling, input validation, and a student data table.

 ## Features

 - Student registration form
- Full Name input field
- Email input field
- Password input field
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth selection
- Register button
- Submitted students table with dummy data
- Pink and purple color theme
- Hover effects for buttons and table rows
- Input focus effects
- Basic HTML form validation using `required`

 ## Technologies Used

 - HTML5
- CSS3

 ## Form Fields

 The registration form contains:

 - Full Name – Enter the student's name.
- Email – Enter a valid email address.
- Password – Enter a password.
- Gender – Select Male or Female.
- Skills – Select HTML, CSS, and/or JavaScript.
- Date of Birth – Select the student's date of birth.
- Register – Submit the form.

 ## Dummy Student Data

 The table currently contains sample student records:

 - Alice – HTML, CSS
- Bob – JavaScript

 Note: This project is currently a front-end project. The registration form does not store submitted data in a database.
